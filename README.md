# Tutorial Dock

**操作画面を切り替えずに、ハンズオンを進める。**

Tutorial Dockは、ソフトウェアの操作を実演しながら、手順と補足資料を同じ共有画面に表示するためのWindows向け講師支援アプリです。最初の利用シーンはTableau Desktopのオンラインハンズオンですが、特定のソフトウェアに依存しないことを目指しています。

> 開発準備中：本リポジトリには現在、仕様の草案のみがあります。実行可能なアプリはまだありません。

## 目指す利用体験

- 画面上端に枠のないコンパクトなガイドバーを常設し、その下でTableauなどのアプリを操作する。
- ガイドバーの左側にステップ番号・タイトル・短い説明を、右側に教材で定義したボタンと前後移動を表示する。
- 必要な場合だけ、ボタンから中央の大きな枠なし画像ウィンドウを開く。画像はズーム・ドラッグでき、閉じると操作画面に戻る。
- ガイドバーを折りたたみ、作業領域を広げられる。
- Windowsの画面全体をZoom/Teams等で共有する想定。アプリ単体の画面共有では別ウィンドウが映らない場合があります。

## 教材の形式

教材はローカルのYAMLファイルでステップ・説明文・ボタンを定義し、画像を相対パスで参照します。アプリ本体と教材は別々に管理できます。

```text
my-workshop/
├── lesson.yaml
└── images/
    ├── how-to.png
    └── result.png
```

```yaml
title: Tableau 基本操作
steps:
  - id: bar-chart
    title: 棒グラフを作成
    description: 「カテゴリ」を列、「売上」を行に配置します。
    buttons:
      - label: 操作方法
        action: image
        src: images/how-to.png
      - label: 完成例
        action: image
        src: images/result.png
```

※上記は設計案のサンプルです。正式なスキーマは実装・検証に合わせて確定します。

## MVPの範囲

Windows用のインストール不要なexe、YAML教材選択と手動再読み込み、枠なしガイドバー、ステップ移動、画像表示とズーム、表示先ディスプレイ選択、Windowsの作業領域予約（AppBar連携）を目指します。グローバルショートカット、教材編集UI、動画・HTMLスライド、自動更新はMVP対象外です。

- [要件定義](docs/requirements.md)
- [技術設計案](docs/design.md)

## 開発方針

最終MVPの要件を維持しながら、段階的に動作検証します。まず表示と教材読み込みを成立させ、Windows AppBar連携や複数ディスプレイでの挙動を検証します。AppBarの正常動作はMVPの完了条件であり、失敗時のフォールバックだけでは完成とみなしません。
