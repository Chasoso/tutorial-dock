# Baseline: ガイドバー基本表示

## 基準の扱い

本来の正本は `docs/requirements.md` だが、このcheckoutには存在しない。したがって、下記は今回の依頼文に明示された対象範囲から作った**暫定検証基準**であり、既存要求から抽出した確定版ではない。要求IDも正式な製品仕様IDではなく、このTechnical Spike内だけの仮IDである。

## 明示された対象要件

| ID | 暫定要件 | 期待する確認 |
|---|---|---|
| TD-GUIDE-01 | Windows画面上部にガイドバーUIを表示する | UIが上部に表示される |
| TD-GUIDE-02 | 通常表示時の固定高さを持つ | 表示中に高さが変動しない |
| TD-GUIDE-03 | 現在のステップ番号と総ステップ数を表示する | fixtureの現在値と総数が表示される |
| TD-GUIDE-04 | ステップタイトルと説明文を表示する | 現在ステップのタイトルと説明が表示される |
| TD-GUIDE-05 | 前ボタンで前ステップ、次ボタンで次ステップへ移動する | クリック後に表示内容と番号が遷移する |
| TD-GUIDE-06 | 先頭・末尾で範囲外操作を防止する | 先頭で前、末尾で次を押しても状態が変わらない |
| TD-GUIDE-07 | 教材未読み込み時の表示を持つ | 空fixture時に未読み込み状態が表示される |
| TD-GUIDE-08 | マウスで操作できる | 前・次ボタンをマウスクリックできる |

## 暫定値・未確定事項

- 約90pxは暫定値であり、確定値として仕様化しない。
- 教材データは読み込み・検証済みの固定fixtureを使う。
- fixture利用は検証スコープを限定するためであり、MVPからYAML読み込みを除外する決定ではない。
- 未指定のアクセシビリティ、レスポンシブ挙動、キーボード操作、エラー文言、デザイン詳細は今回の基準から推測しない。

## 範囲外

Windows AppBar API、作業領域予約、折りたたみ、マルチディスプレイ、画像ビューア、YAMLパーサー、ポータブルexe、グローバルショートカット。

## 生成物評価チェックリスト

1. TD-GUIDE-01〜08が欠落なく対応しているか。
2. 約90pxを確定要件へ昇格していないか。
3. 範囲外機能の完成を前提にしていないか。
4. 先頭・末尾・教材未読み込みが検証可能な受入条件になっているか。
5. Electron等の実装方式が仕様段階へ不要に混入していないか。
6. fixtureの扱いをYAML機能の恒久的除外と誤解していないか。
